# Advocacia — site institucional

Site de escritório em React com apresentação de áreas de atuação e contato.

## Recursos

Menu móvel, modais e formulário com validação e estado de confirmação.

## Tecnologias

React, JavaScript e Vite. Consulte package.json para as dependências e versões declaradas.

## Executar localmente

Use Node.js e npm compatíveis com as dependências declaradas:

```sh
git clone https://github.com/Felipegaldinos/advocacia.git
cd advocacia
npm install
npm run dev
```

Abra o endereço exibido no terminal. `npm run build` gera a versão de produção. `npm run preview` permite visualizar esse build.

## Onde começar no código

- `src/App.jsx` — ponto de entrada para entender o projeto.

## Estado atual

O formulário observado valida e mostra confirmação local; não há envio no seu manipulador. O conteúdo principal está concentrado em App.jsx.
